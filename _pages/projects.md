## Instance Segmentation for Crack Detection
<!-- Left side: project description -->
<div style="width: 70%; float: left;">
  Automated crack detection using instance segmentation models trained on annotated surface imagery. Cracks are often subtle and irregular in shape, making instance segmentation a more effective approach than standard object detection.

  Experimenting with different versions of YOLO models to evaluate performance and generalization on this task, starting with YOLOv11 and YOLOv8.

<br/><a href="https://app.roboflow.com/shayan-xmj2k/crack-detection-using-instance-segmentation-cjisv/overview">Roboflow Project</a>
  <br/><span style="color:#FFA500;">Keywords:</span> Computer Vision, YOLOv8, YOLOv11, Object Detection, Instance Segmentation
</div>

## Pick-and-Place to Recycle Objects
<!-- Left side: project description -->
<div style="width: 70%; float: left;">
  Automating recycling operation using a robotic manipulator in a Gazebo environment. Implementing a pick-and-place algorithm by employing point cloud processing for object detection and applying RRT path planning with real-time ROS integration to achieve collision-free trajectories.

<br/><a href="link-to-the-project">Project Link</a>
  <br/><span style="color:#FFA500;">Keywords:</span> GNU/Linux, ROS, MATLAB, Gazebo, Path Planning, Pointcloud, Industrial Robots

## Collaborative Pick-and-Place with Mobile Robot
<!-- Left side: project description -->
<div style="width: 70%; float: left;">
  Developed a collaborative pick-and-place:
  
- First manipulator picks the object from a conveyor belt and places it onto a mobile robot.
* Mobile robot autonomously navigates to deliver objects to a second manipulator.
+ Second manipulator pick the object from the mobile robot and places it into a bin.

<br/><a href="link-to-the-project">Project Link</a>
  <br/><span style="color:#FFA500;">Keywords:</span> ROS, GNU/Linux, Python, Gazebo, Path Planning, Mobile Robots, Manipulations
